01 / The Core Problem

Defending the Supply Chain with IBM Bob 2.0

Why traditional vulnerability scanners fail against day-zero malicious dependencies.

⚠️ The Blind Spot

Zero-Day Attacks

Conventional SCA tools (Snyk, Dependabot) rely on published CVE databases. Newly published malicious packages or poisoned versions have zero CVEs when first merged.

⚡ The Attack Vector

Silent Install Scripts

Innocent-looking packages run preinstall and postinstall hooks during npm install, exfiltrating cloud secrets (AWS_SECRET_ACCESS_KEY) to remote endpoints.

🛡️ The Solution

Supply Chain Bouncer

A zero-execution review system coordinating 3 parallel IBM Bob subagents, interactive developer review, and a deterministic gate bound to cryptographic input digests.

🔒 Zero Untrusted Code Execution ⚡ 100% In-Memory Static Inspection 📦 Zero External Dependencies

💡 Key Design Principle: Separation of Concerns — Deterministic code collects facts; IBM Bob interprets and reasons; the human makes the policy decision; the local gate enforces cryptographically; and Bob autonomously fixes the pull request.
03 / Architecture & Invariants

Security Invariants & Threat Boundaries

Engineered for defense-in-depth with zero external runtime dependencies.

🛡️

Zero Target Code Execution

All inspection happens on static text buffers and AST parsing. Lifecycle hooks, binaries, and package scripts are strictly treated as untrusted data and never invoked.

Decompression Defense

Guards against zip bombs via maxOutputLength, rejects directory traversal (../), and rejects archive symlinks.

🔐

Cryptographic Input Binding

Decisions are permanently bound to a fixed-order SHA-256 array of input digests (base/head manifests, lockfiles, policy rules, scanner release code, and evidence).

Tamper Detection

Altering even 1 whitespace character in an approved lockfile invalidates approval and causes the gate to fail closed (Exit code 2).

Zero External Dependencies: 100% built on Node.js v24 LTS built-in modules to eliminate scanner poisoning.

06 / Limitations & Roadmap

Security Disclosures & Future Roadmap

Honest engineering disclosures and path to enterprise production readiness.

Current Operating Boundaries

  • Mode Declaration: Runs in explicitly declared trusted-local-demo mode (assumes trusted developer workspace).
  • Static Analysis Scope: Flags suspicious code syntax (e.g. execSync, process.env), but cannot decrypt dynamic runtime-fetched payloads without sandboxing.
  • Advisory AI: Subagents cannot bypass hard integrity violations or approve dependencies without human authorization.

Enterprise Production Roadmap

  • Cryptographic Decision Signing: Asymmetric Ed25519 reviewer keypairs signed via Node.js crypto.
  • Remote GitHub Actions Gate: Automated pull request enforcement with branch protection checks (supply-chain-bouncer/gate).
  • Live Sigstore/SLSA Verification: Native adapter querying npm's public provenance transparency logs.
